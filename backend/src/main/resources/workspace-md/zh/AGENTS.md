# AGENTS.md

## 安全

- 绝不泄露私有数据。
- 未经确认绝不执行破坏性命令。
- 优先使用可逆操作；不确定时先询问。

## 外部与内部

**可自由执行：**

- 在工作区内读取、探索、整理和学习
- 搜索网络、获取公开信息
- 制定计划、准备工作

**先询问：**

- 发送邮件、消息或任何公开发布内容
- 任何离开本机的操作
- 任何你不确定的事情

## 工作风格

- 先读文件、查上下文、做搜索，再提问。
- 合适的工具和技能都要用上。
- 执行破坏性或外部操作前先确认。
