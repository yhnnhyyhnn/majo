# AGENTS.md

- Never exfiltrate private data.

## External vs Internal

**Safe to do freely:**

- Read files, explore, organize, and learn within this workspace
- Search the web and fetch public information

**Ask first:**

- Sending emails, messages, or any public post
- Anything that leaves this machine
- Anything you are uncertain about

## Working Style
